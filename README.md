# 北疆随行

适合手机浏览器的北疆 8 日旅行助手，按携程 28776261 A 线整理，出发日期为 2026 年 9 月 19 日。行程以最终出团通知为准。

## 使用

- 顶部选择全程或某一天，地图显示行程顺序；虚线不是导航道路。
- 点击“定位到我”，允许浏览器定位后查看已收录的附近风景、文化和餐饮地点。
- “全部”汇总三个分类；点卡片查看简介和详细介绍，也可分别收听。
- 每天气温可选择行程日期，或未来 3 / 7 / 14 天（含今天），并选择沿途地点。打开网页自动同步，可手动刷新。数据源最多提供 16 天预报；缺失数值不会用猜测或季节平均代替。超过一小时的数据会显示“上次数据”；更新失败保留缓存及时间。过去日期返回的天气标为模型数据。
- 风景、文化和地方美食配有对应图片，原有简介和详细介绍保留；餐馆仅在有对应品类照片时展示明确标注的示意图，其余显示“店铺照片待补充”。6 段“路上也值得看”介绍 D2—D7 沿途背景，可单独收听，不增加原行程停靠点。卡片与详情保留完整画面，避免截掉湖岸、草地或菜品主体。
- 点击“开启到点播报”并允许定位。网页保持前台时，在收录景点约 500 米范围内触发；天池、喀纳斯、赛里木湖按公开地图湖岸约 800 米判断，魔鬼城和峡谷按地图区域判断。定位误差超过 200 米或位置过期不触发。
- 每个景点在本次打开中自动播报一次，间隔至少 90 秒。手动收听不受此限制。“停止播报”立即停止当前语音并关闭自动播报；锁屏、切换应用或离开页面也会停止。
- 默认使用预生成的 AI 自然女声（晓晓），讲解文案采用口语表达。音频按需从本网站加载，点“试听声音”可试听。也可切换到手机中文声音，该模式需要浏览器支持 Web Speech API 及中文语音服务。手机音量、定位权限和后台限制会影响实际体验。

## 发布与本地运行

本项目为纯静态 HTML / CSS / JavaScript，无账号系统、无后端、无需 API 密钥。

GitHub Pages 使用 main 分支根目录发布，保留 `.nojekyll`。网页与代码公开，包含行程和出发日期；别人打开网页不需要 GitHub 或 ChatGPT 账号。

本地预览：安装 Node.js 后，在本目录运行 `node preview.mjs`，用浏览器打开输出的 localhost 地址。直接双击 `index.html` 的 file:// 方式可能无法加载数据或定位。跨设备分享建议使用 HTTPS 的 Pages 链接。地图和实时天气需要网络，这不是完整离线地图。

## 文件

`index.html` 和 `styles.css` 为界面，`app.js` / `model.js` 处理地图与筛选，`weather*.js` 处理天气，`voice*.js` / `narrator.js` 处理语音，`media.js` 处理配图。内容数据位于 `data/trip.json`，播报范围位于 `data/voice-areas.json`；图片和音频位于 `images/`、`audio/`。所有资源使用相对路径，支持 GitHub Pages 项目子目录。
